Scoring and interpretation

Apply capability value set: UK index runs from no capability (0) to full capability (1). Zero is not death.

Range or output: 0–1 using UK tariff

Direction: Higher index values indicate greater capability.

ICECAP-A capability state

Profile

Range/output: Five-attribute profile

Derivation: One level for each capability attribute

Profile is valued, not simply summed.

ICECAP-A index

Capability index

Range/output: UK tariff 0–1

Derivation: Apply the ICECAP-A tariff

Zero means no capability, not death.

Tariff/value-set dependent
