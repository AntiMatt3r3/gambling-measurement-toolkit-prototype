Scoring and interpretation

Value five-digit profile with appropriate country-specific tariff. EQ VAS is separate; do not sum dimension levels as utility.

Range or output: No universal index range. Report a five-digit profile, EQ VAS 0–100, and—where used—an index from the selected value set.

Direction: Higher EQ VAS/index values indicate better health; higher dimension levels indicate more severe problems.
